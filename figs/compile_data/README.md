# How to compile experimental data

- [`mk_results_csv.py`](https://github.com/msakarvadia/llm_optimizer/blob/main/figs/compile_data/mk_results_csv.py): `python mk_results_csv.py` will iterate through the general_rollout and population_dynamics (both for OPRO and production-grade optimizers) and compile it into a <2GB CSV. Use this CSV to make experimental figures. Too big to upload to github.
- [`../../llm_optimizer/population_curation_utils.py`](https://github.com/msakarvadia/llm_optimizer/blob/main/llm_optimizer/population_curation_utils.py): will both curate initialization populations for the OPRO harnesses _and_ compile the results from the parallel discovery experiments. Results are smaller so can be uploaded to github. See results [here](https://github.com/msakarvadia/llm_optimizer/blob/main/llm_optimizer/parallel_zeroshot_results.csv)
